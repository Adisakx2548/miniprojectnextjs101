# ระบบจัดการสต็อกสินค้าขนาดเล็ก (Small Inventory Management System)

## สไลด์นำเสนอ Wireframe UX

โปรเจกต์นี้เป็นส่วนหนึ่งของรายวิชา **Mini Project Next.js 101** โดยมีวัตถุประสงค์เพื่อออกแบบและนำเสนอ **Wireframe UX** สำหรับ **ระบบจัดการสต็อกสินค้าขนาดเล็ก (Small Inventory Management System)** เพื่อแสดงแนวคิดการจัดวางหน้าจอ (Layout), ประสบการณ์ผู้ใช้ (User Experience) และโครงสร้างการทำงานของระบบ ก่อนนำไปพัฒนาเป็นเว็บแอปพลิเคชันด้วย Next.js ในขั้นตอนถัดไป

## 🎯 วัตถุประสงค์ของโปรเจกต์

* ออกแบบระบบจัดการสต็อกสินค้าขนาดเล็กที่ใช้งานง่าย

* ออกแบบ Wireframe UX เพื่อแสดงภาพรวมของระบบ

* วางโครงสร้างหน้าจอการใช้งานอย่างเป็นระบบ

* ช่วยให้ทีมเข้าใจทิศทางการพัฒนา Frontend ตรงกัน

* เตรียมความพร้อมสำหรับการพัฒนาด้วย Next.js

---

## 📐 ขอบเขตงาน (Scope)

* ออกแบบหน้าแสดงรายการสินค้า (Product List)
* ออกแบบหน้าจอเพิ่ม / แก้ไข / ลบสินค้า
* ออกแบบการแสดงสถานะสต็อก (เช่น สินค้าใกล้หมด)
* ออกแบบโครงสร้างหน้าหลัก (Dashboard)
* คำนึงถึงความง่ายต่อการใช้งาน (Usability)
* เน้น UX ที่เข้าใจง่ายและเหมาะกับผู้ใช้ทั่วไป
